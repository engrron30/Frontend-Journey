# HTML Basics

In this project, we are going to display and experiment HTML tags and elements.

## Simple HTML Page

Start with a simple HTML. Open this file to display it in your browser <br>

```
<!DOCTYPE html>
<html>
<head>
    <title>Hello, User!</title>
</head>
<body>
    <h1>Hello User!</h1>
    <p>Today, we are learning HTML.</p>
</body>
</html>
```

![First Page](Assets/01_First-Page.png)

You see the usage of <h1> and <p> tags. You can use h2, h3, ... to create subheadings. <br>

```
<body>

    <h1>Head 1</h1>
    <p>h1_p1</p>
    <p>h1_p2</p>
    <p>h2_p3</p>

    <h1>Head 2</h1>
    <p>h2_p1</p>
    <p>h2_p2</p>
    <p>h3_p3</p>

    <h2>Head 3</h2>
    <p>h3_p1</p>
    <p>h3_p2</p>
    <p>h3_p3</p>

</body>
```
